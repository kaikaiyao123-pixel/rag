# 云雀笔记 · 故障排查手册

## 启动类问题

### 启动后白屏，窗口无内容

按以下顺序排查：

1. 检查是否安装了不兼容的插件。以安全模式启动（启动时按住 Shift），
   安全模式下不加载任何插件。若能正常显示，则逐个禁用插件定位问题源。
2. 清理渲染进程缓存：删除 `.lark/cache/render` 目录后重启。
3. 检查显卡驱动。部分旧版驱动与 Electron 的 GPU 加速不兼容，
   可在"设置 → 高级"中关闭硬件加速。

### 提示"知识库目录被占用"

通常是另一个云雀笔记实例或网盘客户端正在写入。关闭所有实例后，
删除 `.lark/lock` 文件再重试。若该文件反复出现，说明有进程持续持有句柄，
Windows 下可用资源监视器搜索该文件路径定位进程。

## 编辑类问题

### 输入中文时出现重复字符

这是输入法与 Electron 的 IME 事件竞争导致的。在"设置 → 编辑"中开启
"兼容输入法模式"可缓解，代价是候选词定位偶尔偏移。

### 粘贴大段内容后卡顿

单次粘贴超过约 5 万字符时，实时预览会阻塞主线程。建议在"设置 → 编辑"中
关闭"实时预览"，改为手动切换预览。或在粘贴后立即按 Ctrl+Shift+V 使用
纯文本粘贴，减少格式解析开销。

### 撤销栈丢失

撤销栈上限默认为 200 步，超出后最早的记录会被丢弃。切换笔记不会清空
撤销栈，但重启应用会。若需要长期回退，请使用版本历史而非撤销。

## 索引与检索问题

### 索引重建耗时过长

重建速度约为每秒 3000~5000 个片段。10 万片段的知识库约需 20~35 秒。
加速手段：

- 将知识库放在 SSD 上（机械盘会慢 4~6 倍）。
- 在"设置 → 索引"中排除附件目录与 `.git` 目录。
- 关闭"索引附件文件名"，该选项会显著增加文件系统调用次数。

### 索引文件体积异常增大

正常情况索引体积约为正文总量的 25%~40%。若明显超出：

1. 检查是否误将大体积日志文件纳入知识库。单个文件超过 10 MB 时建议排除。
2. 执行"设置 → 索引 → 压缩索引"，会移除低频词项（出现次数少于 3 次）
   的倒排记录。压缩后体积通常下降 30%~50%，代价是生僻词检索召回下降。

### 检索结果中缺少明显相关的笔记

除常见问题中列出的排查步骤外，还需检查：

- 该笔记是否被"排除索引"规则匹配（可在笔记属性中查看）。
- 笔记是否处于"加密笔记本"中且当前未解锁。
- 笔记是否超过 1 MB。超过该大小的笔记只索引前 1 MB 内容。

## 同步类问题

### 冲突副本无法合并

若冲突副本与主文件差异过大，自动合并会失败。此时可用"工具 → 差异对比"
手动合并。差异对比支持三方视图，中间列为共同祖先版本。

### 局域网同步找不到设备

1. 确认两台设备在同一网段（`192.168.1.x` 与 `192.168.2.x` 属于不同网段）。
2. 检查系统防火墙是否放行 UDP 5353（mDNS）与 TCP 47820（同步服务）。
3. 部分企业网络会隔离客户端之间的通信（AP 隔离），此时局域网同步不可用。

## 数据恢复

### 误删笔记如何恢复

笔记删除后会移入 `.lark/trash/` 并保留 30 天。可在"文件 → 回收站"中还原。
超过 30 天后，若开启过 Git 同步，可用 `git log --diff-filter=D` 找到删除
提交并恢复。

### 知识库目录损坏

若目录结构损坏但文件仍在，可用"工具 → 重建知识库"扫描指定目录，
重新生成 `.lark` 元数据。该操作不会修改笔记正文，但会丢失标签、
双向链接缓存与版本历史索引。

## 日志位置

| 平台 | 路径 |
| --- | --- |
| Windows | `%APPDATA%\LarkNote\logs\` |
| macOS | `~/Library/Logs/LarkNote/` |
| Linux | `~/.config/LarkNote/logs/` |

日志按天滚动，默认保留 7 天，单个文件上限 10 MB。
