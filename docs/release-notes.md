# 云雀笔记 · 版本发布记录

## 2.4.0（2026-08-18）

### 新增

- 检索支持正则表达式，写法为 `/表达式/`，单次执行上限 2 秒。
- 智能笔记本支持嵌套，最大深度 3 层。
- 索引支持"按需加载"，超过 5 万篇笔记时可显著降低常驻内存。
- 新增"压缩索引"功能，可移除低频词项的倒排记录。

### 优化

- 索引重建速度提升约 35%，主要来自分块阶段的字符串分配优化。
- 中文检索的标题加权系数由 1.2 调整为 1.8，FAQ 类文档的首条命中率提升。
- 版本快照的写入改为追加式，单次保存耗时从 45 ms 降至 12 ms。

### 修复

- 修复了在 Windows 上路径含中文时索引写入失败的问题。
- 修复了表格单元格内换行导致导出 PDF 时列宽计算错误的问题。
- 修复了删除笔记后其历史快照未被计入回收站体积统计的问题。

## 2.3.0（2026-05-06）

### 新增

- 局域网直连同步，支持 mDNS 自动发现与 TLS 1.3 加密。
- 插件系统开放 `onIndexBuild` 钩子。
- 导出新增 JSON 格式，包含完整元数据。

### 优化

- 插件运行在独立子进程，插件崩溃不再影响主程序。
- 剪藏内容写入前增加本地清洗，移除追踪像素与内联脚本。

### 修复

- 修复了 Obsidian 库导入时 front matter 中 `aliases` 字段丢失的问题。
- 修复了双屏环境下候选词窗口定位偏移的问题。

## 2.2.0（2026-02-11）

### 新增

- 数学公式渲染（KaTeX），支持行内与独立公式。
- Mermaid 图表支持，覆盖流程图、时序图、甘特图、类图、状态图。
- 支持导入印象笔记 `.enex` 导出包。

### 变更

- 索引格式升级至 v3，升级后首次启动会重建索引。旧版索引会保留
  7 天后自动清理。

## 2.1.0（2025-11-20）

### 新增

- 双向链接支持链接到指定章节：`[[笔记#章节]]`。
- 标签支持层级写法：`#技术/数据库`。
- 冲突解决策略可配置。

### 优化

- 中文分词由单字切分改为二元切分，检索召回率提升明显，
  索引体积增加约 2.4 倍。

## 2.0.0（2025-08-02）

这是第一个稳定版本，标记为 2.0 是因为数据格式与 1.x 不兼容。

### 主要变化

- 知识库改为纯 Markdown 文件存储，`.lark` 目录只存放索引与元数据。
  1.x 的单一数据库文件格式不再支持，需通过迁移工具转换。
- 检索由 SQLite FTS5 改为自研倒排索引，支持标题加权与词项覆盖率加权。
- 界面重写，引入可自定义主题。

### 迁移说明

1.x 用户首次启动会看到迁移向导。迁移会保留原数据目录，转换完成后
需手动确认删除。建议迁移前先完整备份原目录。

## 1.4.0（2025-04-15）

最后一个 1.x 版本，仅包含安全修复：

- 修复了剪藏功能在处理超长 URL 时的缓冲区溢出。
- 修复了局域网发现服务的拒绝服务风险（CVE 编号待分配）。

1.x 系列自此停止维护。
