# 云雀笔记 · 常见问题

## 如何导入已有笔记？

支持四种导入方式：

1. **Markdown 文件夹导入**：选择"文件 → 导入 → Markdown 文件夹"，选中目录后
   软件会递归扫描所有 `.md` 文件，并按原有的子目录结构建立笔记本。
2. **Obsidian 库导入**：直接选择 Obsidian 仓库根目录即可，`[[双向链接]]`、
   `#标签` 和 YAML front matter 会被完整保留。
3. **印象笔记导出包导入**：支持 `.enex` 格式，图片附件会自动解压到
   `attachments/` 目录并重建引用关系。
4. **纯文本批量导入**：`.txt` 文件会以文件名为标题导入，编码自动识别
   UTF-8、GBK 与 Big5。

导入过程中如果遇到同名笔记，软件会询问是"覆盖""保留两者"还是"跳过"，
也可以勾选"对全部冲突应用此选择"。

## 导出支持哪些格式？

- **Markdown**：保留双向链接语法，适合迁移到其他工具。
- **PDF**：支持自定义页面尺寸、页边距和是否包含反向链接附录。
- **HTML 单文件**：把正文与图片打包为一个 `.html` 文件，便于分享。
- **JSON**：包含全部元数据的结构化导出，适合二次开发。

导出时可以选择范围：单篇笔记、整个笔记本，或全部知识库。

## 检索不到我确定存在的内容怎么办？

按以下顺序排查：

1. 确认笔记所在的目录已被加入知识库。未纳入知识库的文件不会被索引。
2. 在"设置 → 索引"中点击"重建索引"。索引损坏或版本升级后需要重建。
3. 检查是否开启了"仅搜索当前笔记本"过滤器，该过滤器会限制检索范围。
4. 中文检索基于二元切分，单字查询（例如只输入"税"）命中率较低，
   建议输入至少两个汉字，例如"税务"。

## 支持多设备同步吗？

官方不提供云同步服务，但提供三种自建同步方案：

- **Git 仓库**：把知识库目录初始化为 Git 仓库并推送到私有远端，
  软件内置了自动提交与冲突提示。
- **网盘目录**：将知识库放在坚果云、OneDrive 等同步盘中。注意避免多台
  设备同时编辑同一篇笔记，否则可能产生冲突副本。
- **局域网同步**：在"设置 → 同步"中开启局域网共享，同一网段内的设备
  可以发现并同步彼此的变更。

## 数据存储在哪里？

默认位置为 `文档/云雀笔记/`，可在"设置 → 存储"中修改。修改后旧数据不会
自动迁移，需要手动移动文件后重新指向。

## 是否支持移动端？

提供 iOS 与 Android 客户端，功能限于阅读、编辑和检索，不支持网页剪藏与
版本对比。移动端通过局域网同步或第三方网盘与桌面端交换数据。
