# 云雀笔记 · 检索语法与高级搜索

## 基础检索

在检索框输入任意关键词即可。检索默认覆盖笔记标题、正文、标签与附件文件名，
并按相关度排序。中文检索基于二元切分，因此单字查询命中率较低，建议输入
两个以上汉字。

## 检索运算符

云雀笔记支持一套类 Lucene 的检索运算符：

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `空格` | 逻辑与（AND） | `同步 冲突` |
| `OR` | 逻辑或 | `同步 OR 备份` |
| `-` | 排除 | `导出 -PDF` |
| `"..."` | 短语精确匹配 | `"局域网同步"` |
| `title:` | 限定标题 | `title:定价` |
| `tag:` | 限定标签 | `tag:待整理` |
| `path:` | 限定路径 | `path:技术/数据库` |
| `file:` | 限定文件名 | `file:*.pdf` |
| `created:` | 限定创建时间 | `created:>2026-01-01` |
| `updated:` | 限定更新时间 | `updated:7d` |

时间表达式的相对写法支持 `7d`（7 天内）、`2w`（2 周内）、`3m`（3 个月内）、
`1y`（1 年内），也可用 `>` `<` 配合绝对日期。

## 组合示例

```
# 技术目录下提到"索引"但不是"数据库"的笔记，最近一个月内更新过
path:技术 索引 -数据库 updated:30d

# 标题含"发布"且带"归档"标签
title:发布 tag:归档

# 精确匹配短语，排除草稿
"向量检索" -tag:草稿
```

运算符可以任意组合，但同一前缀限定符不可重复使用（如同时写两个 `tag:`
时只保留最后一个）。

## 正则表达式检索

在检索框输入 `/\d{4}-\d{2}-\d{2}/` 形式的表达式即可启用正则匹配。正则检索
不参与相关度排序，结果按文件路径排序返回。

正则检索仅在已建索引的纯文本内容上执行，不支持跨行匹配，单次执行上限为
2 秒，超时会被中断并提示缩小范围。

## 保存与复用检索

点击检索框右侧的"保存"按钮可将当前查询保存为"智能笔记本"。保存时可以选择
是否固化为静态列表：选择固化后，笔记本内容不会随新笔记出现而自动更新。

智能笔记本支持嵌套，但嵌套深度不超过 3 层，避免出现循环引用。

## 排序与分组

检索结果支持按相关度、更新时间、创建时间、标题字典序排序。默认按相关度，
相关度相同时按更新时间倒序。

分组视图可以按笔记本、标签或时间（日/周/月）聚合结果。分组视图下不展示
片段预览，只展示标题与路径，以提升大量结果时的滚动性能。

## 检索性能说明

索引常驻内存的部分约为词项数与片段数的线性函数。在 1 万篇笔记、约 12 万个
片段的规模下，索引占用内存约 180 MB，热查询延迟中位数在 20 ms 以内。
超过 5 万篇笔记时建议开启"按需加载索引"，代价是首次查询会有 200~400 ms 的
额外延迟。
