# 云雀笔记 · 安全与隐私说明

## 数据流向

云雀笔记是**本地优先（local-first）**应用。默认配置下，笔记内容、附件、
索引与版本历史全部存放在用户本机，不存在任何形式的数据上传。

软件仅在以下两种情况下会发起网络请求，且均可关闭：

1. **更新检查**：请求版本清单接口，只发送当前版本号与操作系统类型，
   不包含任何用户标识或笔记内容。可在"设置 → 通用 → 隐私"中关闭。
2. **插件网络访问**：由插件主动发起，需用户安装插件时明确授权，且受域名
   白名单限制。内置插件不发起任何网络请求。

## 本地数据保护

### 文件权限

知识库目录在创建时会设置为当前用户可读写（Linux/macOS 权限 `0700`）。
Windows 下会移除 `Everyone` 与 `Users` 组的继承权限。

### 索引加密

索引文件默认明文存储以便用户自行检查。若开启"设置 → 安全 → 加密索引"，
索引会使用 AES-256-GCM 加密，密钥由用户主密码通过 Argon2id 派生
（内存开销 64 MB，迭代 3 次，并行度 4）。开启后每次启动需输入主密码，
且无法通过任何方式找回——忘记密码只能删除索引后重建。

### 版本快照

版本快照存放于 `.lark/history/`，默认不加密。若笔记含敏感内容，建议开启
索引加密并同时勾选"加密版本快照"。

## 剪藏与浏览器扩展

浏览器扩展只在你点击"剪藏"按钮时读取当前页面内容，不会后台扫描浏览历史。
扩展申请的权限清单为 `activeTab`、`storage` 与 `<all_urls>`，其中
`<all_urls>` 用于在任意页面注入剪藏按钮，扩展不会主动访问这些页面。

剪藏内容在写入知识库前会经过一次本地清洗，移除追踪像素、内联脚本与
`onclick` 类事件属性。

## 遥测与统计

**不收集任何遥测数据。** 没有崩溃上报、没有使用行为统计、没有设备指纹。
软件内不包含任何第三方分析 SDK。

如果希望反馈问题，需要手动导出诊断包（"帮助 → 导出诊断信息"），该操作会
明确列出将要打包的文件清单，其中包含日志与配置（已自动脱敏路径中的用户名），
**不包含笔记正文**。

## 第三方依赖

桌面端依赖清单与许可证在"帮助 → 关于 → 开源许可"中完整列出。主要依赖：

| 组件 | 用途 | 许可证 |
| --- | --- | --- |
| Electron | 桌面运行时 | MIT |
| KaTeX | 数学公式渲染 | MIT |
| Mermaid | 图表渲染 | MIT |
| SQLite | 元数据存储 | Public Domain |

软件不包含任何闭源二进制组件。

## 安全建议

- 使用网盘同步时，确认网盘服务商是否提供端到端加密；未提供时，敏感笔记
  建议改为 Git + 私有远端方案。
- 局域网同步会在首次配对时展示对端设备指纹，请核对后再确认配对。
- 插件拥有与主程序相近的文件读写能力，安装第三方插件前请审阅其源码或
  至少确认其声明权限与功能相符。
- 定期检查 `.lark/history/` 目录体积，历史快照包含笔记的历史版本，
  删除笔记并不会自动删除其历史快照。
