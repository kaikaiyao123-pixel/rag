# 云雀笔记 · 产品概述

## 产品定位

云雀笔记是一款面向个人与小型团队的本地优先知识管理工具。它把笔记、待办、
网页剪藏和附件统一存放在用户自己的磁盘上，默认不上传云端，所有索引与搜索
都在本机完成。

目标用户是三类人群：需要长期积累资料的研发人员、需要整理访谈与会议记录的
咨询顾问、以及希望把碎片想法串成体系的独立创作者。

## 核心功能

### 双向链接

在任意笔记中输入 `[[笔记标题]]` 即可建立双向链接。被链接的笔记会自动在
"反向链接"面板中列出所有引用来源，帮助用户从零散记录中发现隐藏关联。

### 本地全文检索

内置基于倒排索引的全文检索，支持中文分词、标题加权和结果高亮。检索完全
离线运行，不需要联网，也不会把笔记内容发送到任何服务器。

### 网页剪藏

浏览器扩展支持三种剪藏模式：正文提取、整页快照、选中片段。剪藏内容会保留
原始 URL 与抓取时间，便于后续追溯来源。

### 版本历史

每次保存都会生成一个快照，默认保留最近 200 个版本或 90 天内的全部版本。
用户可以在时间轴上对比任意两个版本的差异，并回滚到指定版本。

## 数据与隐私

所有数据以纯 Markdown 文件形式存放在用户指定的"知识库目录"中，附带一个
隐藏的 `.lark` 元数据目录用于存放索引和版本快照。由于正文就是普通文本文件，
用户可以随时用其他编辑器打开，也可以直接用 Git 做版本管理。

软件不收集任何使用统计数据。更新检查默认开启，可在"设置 → 通用 → 隐私"中
关闭。
