# 云雀笔记 · Markdown 语法支持

## 支持的语法范围

云雀笔记遵循 CommonMark 0.31 规范，并扩展了任务列表、表格、脚注、数学公式
和 Mermaid 图表。所有语法在编辑区与预览区保持一致，不会出现"预览与导出
结果不同"的情况。

## 基础语法

| 语法 | 写法 | 说明 |
| --- | --- | --- |
| 标题 | `# 一级` ~ `###### 六级` | 一级标题建议只出现一次 |
| 粗体 | `**文本**` | 快捷键 Ctrl+B |
| 斜体 | `*文本*` | 快捷键 Ctrl+I |
| 删除线 | `~~文本~~` | 导出 PDF 时保留 |
| 行内代码 | `` `code` `` | 反引号数量需与内容匹配 |
| 代码块 | 三个反引号 + 语言名 | 支持 180 余种语言高亮 |
| 引用 | `> 文本` | 支持嵌套，最多 5 层 |
| 分割线 | `---` | 单独一行，前后需空行 |

## 扩展语法

### 任务列表

```
- [ ] 未完成
- [x] 已完成
```

任务列表支持在阅读视图中直接勾选，勾选操作会记录到版本历史中。可以在
"设置 → 编辑 → 任务"中配置完成项的自动归档规则。

### 表格

表格支持列对齐（`:` 位置决定左/中/右对齐），但不支持合并单元格。单元格
内可以换行，使用 `<br>` 标签。导出 PDF 时，超过页面宽度的表格会自动缩放，
缩放下限为原字号的 60%，超出部分横向滚动。

### 脚注

```
这是一段文字[^1]。

[^1]: 脚注内容。
```

脚注会统一收集到文末，编号按首次引用顺序重排。

### 数学公式

行内公式用 `$...$`，独立公式用 `$$...$$`。渲染引擎为 KaTeX，支持绝大部分
LaTeX 数学宏包。导出 PDF 时公式会被栅格化为矢量图形，保证放大不失真。

### Mermaid 图表

用 ` ```mermaid ` 代码块包裹即可，支持流程图、时序图、甘特图、类图和状态图。
图表在编辑区实时渲染，渲染失败时会在代码块上方显示具体错误行号。

## 双向链接与标签

`[[笔记标题]]` 建立双向链接，`[[笔记标题|显示文本]]` 可自定义显示文本。
`[[笔记标题#章节]]` 可链接到指定标题。链接到不存在的笔记时，链接会显示为
灰色，点击可直接创建该笔记。

标签使用 `#标签名` 书写，支持中文与空格（需写成 `#待 整理`）。标签层级用
斜杠分隔，如 `#技术/数据库`。

## Front Matter

笔记开头可用 YAML front matter 声明元数据：

```yaml
---
title: 索引设计笔记
tags: [数据库, 索引]
created: 2026-03-12
aliases: [索引笔记, IndexNote]
---
```

`aliases` 中的名称同样可以被双向链接解析到，便于重命名笔记后保持旧链接有效。

## 导出兼容性

导出 Markdown 时，软件会尽量输出标准 CommonMark。以下扩展语法在导出为
纯 Markdown 时会降级：

- Mermaid 图表降级为代码块，并在文末附上渲染后的 SVG 文件路径。
- 数学公式原样保留 LaTeX 源码。
- 任务列表保留 `- [ ]` 形式，但勾选状态会写入 front matter 的 `tasks` 字段。
